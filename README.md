# TUSZ EEG Processing

This project aims to process and crop (segment) EEG signals using the **Temple University Hospital Seizure Corpus (TUSZ)** dataset.

The dataset can be accessed via the following link:
[TUSZ Dataset - NEDC](https://isip.piconepress.com/projects/nedc/html/tuh_eeg/)

## Objectives
To process raw EEG signal data for further analysis, such as seizure detection or signal classification.
